# SIMTELE-WEB — Panel educativo inspirado en Mi Teleférico

## Descripción
Página web de una sola vista con cuatro módulos didácticos: detención de emergencia, mantenimiento, viento y oscilación, y sensores. Está desarrollada con HTML semántico, CSS responsive y JavaScript externo.

**Aviso:** todos los registros, umbrales y cálculos son simulaciones educativas. No son límites ni procedimientos operativos reales de Mi Teleférico.

## Estructura
- `index.html`: estructura y formularios.
- `css/styles.css`: diseño, colores y adaptación a celulares.
- `js/script.js`: cálculos, eventos, arreglos, DOM, validaciones y almacenamiento local.

## Cómo ejecutar
1. Descarga y descomprime el proyecto.
2. Abre la carpeta `SIMTELE-WEB` en Visual Studio Code.
3. Abre `index.html` en el navegador (puedes usar Live Server).
4. Prueba los cuatro módulos.

## Pruebas mínimas del desafío
1. Emergencia: velocidad `72` y reacción `3` deben dar `60.00 m`.
2. Mantenimiento: agrega dos componentes, comprueba que aparezcan dos filas, elimina uno y verifica que quede una.
3. Viento: introduce `10`, `20`, `30`, `40`, `50`; promedio `30` y máximo `50`.
4. Sensores: `SEN-001` debe aceptarse; `SEN-1` y el campo vacío deben rechazarse.

## Publicar en GitHub Pages
1. Crea un repositorio público en GitHub.
2. Sube `index.html`, `css/`, `js/` y `README.md`.
3. En el repositorio entra a **Settings → Pages**.
4. En Build and deployment selecciona **Deploy from a branch**.
5. Elige `main` y `/ (root)`, guarda.
6. Espera la publicación y copia la URL que GitHub Pages muestra.
